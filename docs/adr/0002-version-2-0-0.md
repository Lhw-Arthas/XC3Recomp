# ADR 0002: Supported version: 2.0.0

- **Status:** Accepted · **Date:** 2026-10-17
- **Requirements:** FR-003

## Decision
Only 2.0.0 (update `v262144`, SDK 9.3.1). `main` build-id: `7e1df8e08d60544b…`.

## Reason
The generator produces code for exact addresses. The last update is the most stable.

## Alternatives considered
Supporting the base 1.0.0: worse stability and a larger test surface.
